# Product Overview

wxauto is a Python library for automating WeChat desktop application interactions on Windows. It provides programmatic control over WeChat through UI automation, enabling developers to:

- Send and receive messages programmatically
- Monitor chat conversations with callback functions
- Handle different message types (text, images, videos, etc.)
- Automate WeChat workflows and integrations

The library is specifically designed for WeChat version 3.9.X on Windows 10/11/Server 2016+ and requires Python 3.8-3.12.

**Key Features:**
- Message listening with customizable callbacks
- Multi-language support (Chinese, Traditional Chinese, English)
- File download capabilities
- Quote/reply functionality
- Thread-safe message handling

**Target Use Cases:**
- Chat automation and monitoring
- WeChat integration for business workflows
- Educational and research purposes for UI automation techniques

**Important:** This is for educational/learning purposes only - not for production or commercial use.
